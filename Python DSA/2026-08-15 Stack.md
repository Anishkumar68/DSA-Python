# Stack Theroy:

A **Stack** is a linear data structure that restricts the insertion and deletion of elements to only one end, called the **Top**.
# LIFO 
* **The Golden Rule:** **LIFO** (Last-In, First-Out). The last element you put into the stack is the first one you take out. *(Sometimes also called FILO: First-In, Last-Out).*
* **Time Complexity:** Because we only interact with the "Top", adding or removing an element takes **O(1)** time. This means it is incredibly fast, regardless of how many items are in the stack!

### 3. Core Operations (The Vocabulary)
To use a stack, you only need to know these 4 basic operations:

1. **`push(item)`**: Adds an item to the top of the stack.
2. **`pop()`**: Removes and returns the top item. *(If the stack is empty, this causes an "Underflow" error).*
3. **`peek()` or `top()`**: Returns the top item *without* removing it. (Just taking a quick look).
4. **`isEmpty()`**: Returns `True` if the stack has no elements, `False` otherwise.

---

### 4. Step-by-Step Example
Let’s trace the logic. Imagine an empty stack. We will use the `push` and `pop` operations.

| Action | Stack State (Bottom -> Top) | What happened? |
| :--- | :--- | :--- |
| **Start** | `[ ]` | Stack is empty. |
| `push(10)` | `[10]` | 10 is at the Top. |
| `push(20)` | `[10, 20]` | 20 is now at the Top. |
| `push(30)` | `[10, 20, 30]` | 30 is now at the Top. |
| `peek()` | `[10, 20, 30]` | Returns **30**. Stack doesn't change. |
| `pop()` | `[10, 20]` | Removes and returns **30**. 20 is now Top. |
| `pop()` | `[10]` | Removes and returns **20**. 10 is now Top. |

---

### 5. Why do we care? (Real-World Applications)
You use stacks every day without knowing it!
* **The "Undo" feature (Ctrl+Z):** Every action you take is `push`ed onto a stack. When you hit Undo, it `pop`s the last action and reverses it.
* **Browser "Back" Button:** Every website you visit is pushed to a stack. Clicking back pops the current site and takes you to the previous one.
* **Function Calls:** When a program calls a function, it pauses the current function, pushes its state onto the "Call Stack", and runs the new function.
